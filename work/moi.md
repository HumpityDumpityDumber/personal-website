MOI is a chat application concept based on the frustration with Discord. Alongside the UI design, I also created an infrastructure design for this application as well. 

This project first started under the name Tea, but it became apparent this is not a great name for a mobile application after the incident involving the already existing application named Tea.

![Very early version of the Tea UI](/assets/projects/moi/Pasted image 20261013113229.png)
*Very early version of the Tea UI*

At first it started as a desktop application just like the Discord desktop application. As time went on, I expanded on the UI and tried to make it double as a mobile UI. I started taking inspiration from apps like WhatsApp and Telegram until I decided to make the UI fully mobile-centric.

![Tea UI in late desktop stages](/assets/projects/moi/Pasted image 20261013113809.png)
*Tea UI in late desktop stages*

Prior to the mobile pivot, the UI was becoming quite polished, but was still missing something.

![Polished Desktop UI Layout](/assets/projects/moi/Pasted image 20261013114028.png)

This was around the point I realized that I was oversimplifying the desktop UI and it would be better to focus on mobile, especially since messaging has more general use on mobile.

![Early Mobile Layout Pivot](/assets/projects/moi/Pasted image 20261013114248.png)

Now we get to the present version where I polished the way messages are displayed and implemented the input bar being swipe-able up and down to access media and profile editing.

![Mobile Message Screen Mockup](/assets/projects/moi/Mobile Message.png)

I took inspiration from how google messages joins consecutive messages together, and I liked how instagram messages put the profile picture next to messages. Names below messages was a deliberate decision aiming to assign a name to large messages, since scrolling is bottom-up in messaging apps. Also being able to place the profile picture next to it, at the bottom left of the messages creates the effect of the messages being a speech bubble originating from them.

![Chat Bar Feature Details](/assets/projects/moi/Chat Bar.png)

The chat bar is multipurpose, allowing you to edit your profile, add media, and have regular input by swiping up and down.
